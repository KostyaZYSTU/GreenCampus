
# GreenCampus

GreenCampus — программно-аппаратный комплекс для формирования экологических привычек студентов и сотрудников университета.

## О проекте

Система объединяет раздельный сбор отходов, цифровую регистрацию экологических действий, начисление баллов и рейтинги пользователей. Предусматривается аппаратный прототип для проверки и сортировки ограниченного набора предметов.

## Функции MVP

- Идентификация пользователя.
- Регистрация подтверждённых экологических действий.
- Начисление и отображение баллов.
- История действий и простой рейтинг.
- Проверка предметов аппаратным прототипом.
- Передача результата проверки в приложение.
- Защита от повторного начисления баллов.

## Структура проекта

- `frontend/` — пользовательский интерфейс.
- `backend/` — серверная логика, API и данные.
- `hardware/` — аппаратный прототип.
- `docs/` — техническая и проектная документация.
- `tests/` — тесты и результаты проверок.

## Подготовка среды разработки

Для работы необходимы Git, редактор кода (например, VS Code) и инструменты, соответствующие выбранному стеку. Конкретные версии и команды установки будут добавлены после утверждения технологий.

## Запуск проекта

Проект находится в разработке. Инструкции по установке зависимостей и запуску появятся после реализации первого запускаемого прототипа.

## Техническое задание

Техническое задание на разработку программно-аппаратного комплекса GreenCampus, версия 1.0 от 21.10.2026, приведено в приложении А проектного отчёта. Ссылка на отдельный файл будет добавлена после размещения в `docs/`.

## Работа с Git

- `main` — стабильная ветка проекта.
- Для каждой задачи создаётся отдельная ветка.
- Название ветки содержит идентификатор задачи.
- Изменения объединяются через Pull Request после проверки другим участником команды.
